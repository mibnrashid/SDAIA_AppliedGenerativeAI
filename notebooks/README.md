# Notebooks

The five Colab labs for the course live here — one per day.

| # | File | Day |
|---|---|---|
| 1 | `day1_first_calls.ipynb` | Day 1 |
| 2 | `day2_retrieval.ipynb` | Day 2 |
| 3 | `day3_agents.ipynb` | Day 3 |
| 4 | `day4_production.ipynb` | Day 4 |
| 5 | `day5_redteam.ipynb` | Day 5 |

`notebooks/index.html` reads `notebooks/notebooks.json` for the Colab links —
edit the JSON, not the HTML.

`project_scaffold.ipynb` is still in this folder but is **no longer handed
out**: students build a repository, not a notebook. It is listed on
`resources/index.html` as optional reference only, and `build.py` no longer
regenerates it.
